01 —DESIGN PHILOSOPHY & IDENTITY
▼

APEX is not a dashboard. It is a trading intelligence terminal. Every design decision must reinforce that it is a professional instrument, not a product. The aesthetic language is: military precision meets financial institution.

CORE AESTHETIC RULES
Tone
Institutional-grade. No friendly rounded shapes. No soft gradients. No marketing aesthetics.
Density
Information-dense by default. Every cm² earns its place. Whitespace is deliberate, not decorative.
Motion
Only functional. Ticker scroll, status pulse, bar transitions. No bounce, no scale pop, no entrance animations.
Color language
Gold = APEX intelligence signal. Green = bullish / profit / live. Red = bearish / risk / loss. Amber = wait / caution / warning. Blue = informational / FVG / neutral.
Reference blend
Image 1 layout bones + Image 2 panel density philosophy + Image 3 amber/glow card aesthetic + Bloomberg data monospace system.
What makes it APEX
News decay scores visible on every headline. Kelly fraction + ATR stop in the bottom bar. SMC zone annotations on charts. No other retail tool shows these.

03 —TYPOGRAPHY SYSTEM
▼

Two fonts. No exceptions. Space Mono carries all machine/data output. DM Sans carries all human-readable content. The contrast between the two IS the design.

FONT 1 — SPACE MONO (data font)
Use for
ALL prices, ALL percentages, ALL timestamps, ALL labels (WORKSPACE, ASSETS), ticker bar, bottom status bar, section headers (9px uppercase), tab labels, signal values (BUY/SELL/WAIT), confidence scores, Kelly fraction, ATR values, news decay scores.
Weights
400 regular + 700 bold only. Bold for prices and signal labels. Regular for everything else.
Why
Fixed-width characters prevent layout jitter when prices update. Bloomberg uses this principle. It reads as "machine output" — authoritative, not designed.
Sizes
9px labels · 10px table data · 11px section values · 14px card subtitles · 20px metric values · 28px hero prices
FONT 2 — DM SANS (human font)
Use for
News headlines, nav item names (Overview, Signal Runner), card description text, tooltip prose, any sentence longer than 4 words.
Weights
300 light for news headlines, 400 regular for nav items, 500 medium for emphasized labels.
Sizes
11px news body · 12px nav items · 13px card descriptions
LETTER-SPACING RULES
Section headers
letter-spacing: .12em — WORKSPACE, ASSETS, SETTINGS, OVERVIEW
Column headers
letter-spacing: .08em — ASSET, SIGNAL, ENTRY, CONFIDENCE
Tab labels
letter-spacing: .08em — OVERVIEW, SMC ZONES, CONSENSUS
Brand name
letter-spacing: .15em — APEX in topbar
Prices / numbers
letter-spacing: 0 — never space out numbers, it ruins alignment
04 —LAYOUT ARCHITECTURE
▼

The layout is a strict 3-zone grid. Nothing bleeds across zones. Each zone has one job.

TOPBAR — 32px fixed height
Brand name left. Live price ticker scrolling center (CSS animation). MT5 status dot + label + UTC clock right. Never taller, never shorter. This is the "always on" strip.
LEFT NAV — 200px fixed width
Workspace nav top. Asset list middle. Two asset quick-view blocks with mini price + ATR bar. Model version + status pinned to bottom. Never collapses on desktop.
MAIN CONTENT — 1fr flex
Tab row top (32px). Content grid fills all remaining space. Bottom status bar 22px fixed. The content grid is a 3-column CSS grid with explicit row heights defined by content type.
RIGHT PANEL — 240px fixed width
MTF alignment section. CSM grid. News feed with decay scores. Risk parameters. Scrollable independently. Never has horizontal scroll. Each section separated by 1px border.
CSS GRID SPECIFICATION
/* Terminal root */ .terminal { display: grid; grid-template-rows: 32px 1fr; height: 100vh; overflow: hidden; } /* Body below topbar */ .body { display: grid; grid-template-columns: 200px 1fr 240px; height: calc(100vh - 32px); overflow: hidden; } /* Main content internal */ .maincontent { display: grid; grid-template-rows: 36px 1fr 22px; } /* Content cards grid */ .content-grid { display: grid; grid-template-columns: 1fr 1fr 1fr; grid-template-rows: 90px 110px 1fr; gap: 1px; background: var(--border); /* gap IS the border */ }
SPACING CONSTANTS
Card padding
12px top/bottom · 14px left/right — always. No exceptions.
Section header gap
margin-bottom: 8px after every .rp-title / .mc-label before content
Table row height
padding: 5px 0 — no fixed height, let content breathe naturally at ~28px per row
Nav item padding
6px top/bottom · 12px left/right — hover background fills this area
Grid gap
1px — the gap color IS the border color (--border). This creates seamless panel joins.

Two identical div blocks side by side, CSS @keyframes translateX(-50%) infinite. No JS. Width: max-content.
Item structure
SYMBOL (gold mono 10px bold) · PRICE (white mono 10px) · CHANGE (green/red mono 10px). Gap: 8px between parts, 24px between items.

Top accent bar
height: 2px, position: absolute top 0, full width. Solid color (no opacity). Gold for confidence, green for signal, blue for news score, red for risk warnings.
Label
Space Mono 9px, --text-muted, letter-spacing .1em, uppercase. margin-bottom: 6px.
Value
Space Mono 20px 700 weight, --text-primary. If value is a signal word (BUY/SELL), use 16px colored text instead.
Sub-row
Two elements: a colored badge pill + a muted context string. Badge: 2px 6px padding, border-radius 2px, rgba background. Context: 9px --text-muted.
Height
Fixed 90px. All three metric cards same height. No responsive variation on desktop.
C · EMBEDDED CHART (inline SVG)
Approach
Raw SVG, not a charting library. viewBox="0 0 640 90". Width 100% of container. Height 90px fixed.
Grid lines
3 horizontal lines at y=22, 44, 66. stroke: --border, stroke-width: 0.5. No vertical grid lines.
Price line
stroke: --green, stroke-width: 1.5, fill: none. Path uses L commands (no curves — terminals are angular).
Area fill
linearGradient: green at 25% opacity top → 0% bottom. Clipped to same path as price line + closed to bottom.
Current price dot
circle r=3 fill --green at last price point. No animation. A static dot anchors the current price visually.
OB zones
rect with rgba(gold, 0.08) fill + rgba(gold, 0.3) stroke 0.5px. 7px Space Mono label "OB" above rect in gold.
FVG zones
rect with rgba(blue, 0.08) fill + rgba(blue, 0.25) stroke 0.5px. 7px Space Mono label "FVG" above in blue.
Y-axis labels
3 price labels left-anchored at x=2. 7px Space Mono --text-muted. No axis line — the grid line IS the axis.

Columns
ASSET (80px) · SIGNAL (60px) · ENTRY (70px) · TP/SL (70px) · RR (60px) · CONFIDENCE (1fr bar)
Header row
9px Space Mono --text-muted, letter-spacing .08em. padding-bottom: 6px, border-bottom: 1px solid --border.
Data rows
10px Space Mono --text-secondary. padding: 5px 0. border-bottom: 0.5px rgba(--border, .5). Hover: background --bg3.
ASSET cell
Gold 700 weight. The gold color here signals "this is the instrument, treat it like a ticker symbol."
SIGNAL cell
BUY = --green. SELL = --red. WAIT = --amber. Font weight 700. This is the most important column.
CONFIDENCE bar
height: 4px track in --bg4. Fill color: green if >75%, amber if 50–75%, blue if <50%. No number — the bar IS the score.
E · SMC STRUCTURE PANEL
Row structure
flex justify-between. Label left (9px mono --text-muted). Value right (10px mono colored).
Active values
Color: --green. Means: the condition is confirmed and active (OB zone price range, FVG range, BOS direction).
Warning values
Color: --amber. Means: detected but unconfirmed (liquidity sweep detected, inducement level identified).
Inactive values
Color: --text-muted. Means: not present in current data (no CHOCH, no sweep).
Special values
PREMIUM/DISCOUNT in --blue. INDUCEMENT level in --amber with the actual price number.
F · MTF ALIGNMENT BARS (right panel)
Structure
Timeframe label (28px, 9px mono --text-muted) + track (flex:1) + signal label (28px right-aligned, 9px mono).
Track
height: 6px, background: --bg3, border-radius: 1px. Fill is colored by signal direction.
Fill colors
BUY = --green fill. SELL = --red fill. WAIT = --amber fill. Fill width = confidence % (0–100%).
Signal label
Matches fill color exactly. BUY in green, SELL in red, WAIT in amber.
Alignment indicator
Count of aligned TFs shown above section: "3/4 ALIGNED" in gold when ≥3 match. "2/4" in amber. "1/4" or "0/4" in red.
G · CURRENCY STRENGTH METER (CSM)
Layout
2-column CSS grid. 6 cells: USD, EUR, GBP, JPY, AUD, CAD. Each cell: background --bg2, border --border, border-radius 3px, padding 5px 7px.
Currency label
9px Space Mono --text-muted. Acts as the "key" for the value below.
Strength value
12px Space Mono 700 weight. Positive (+) = --green. Negative (-) = --red. Near zero (±0.5) = --text-secondary.
Range
-5.0 to +5.0 typical. Values beyond ±3 should be flagged amber/highlighted. This is your "capital flow at a glance" widget.
H · NEWS FEED WITH DECAY
Timestamp
9px mono --text-muted. Format: "08:32 · 14min ago". The "X ago" is calculated live from event time.
Headline
11px DM Sans 300 weight --text-secondary. Line-height 1.3. Max 2 lines. Truncate with ellipsis at 3rd line.
Impact badge
HIGH = rgba(red) bg + red text. MED = rgba(amber) bg + amber text. LOW = rgba(green) bg + green text. 8px mono, 2px 5px padding, border-radius 2px.
Decay score
APEX UNIQUE: "decay: 0.82" in gold 8px mono. This is the exponential decay weight. Shows traders how much influence this event still carries. No other platform shows this number.
Hover state
Headline color transitions to --gold on hover. cursor: pointer. Clicking opens full news context panel.
I · RISK PARAMETERS PANEL
KELLY (HALF)
The calculated position fraction. Shows as decimal (0.23). Label --text-muted, value --text-primary.
ATR (14)
Current ATR value for active asset. Used to calculate stop distance.
STOP level
Exact price level in --red. This is the ATR-anchored stop. Most important risk number.
TARGET level
Exact price level in --green. This is the TP level from the signal.
LOT SIZE
Calculated lot size in --gold. This is the Kelly-normalized position size for 1% account risk.
MAX RISK
Always "1.0% acct" in --amber. Hard ceiling. Non-negotiable. Shows trader the discipline of the system.
J · BOTTOM STATUS BAR
Height
22px fixed. background --bg1. border-top: 1px solid --border.
Items (left → right)
MODEL v4.2 · FEATURES 77 · LAST TRAIN 2d · ACCURACY 71.3% · KELLY 0.23 · LOT 0.08 · ATR STOP 18.2 pip · [spacer] · SESSION LONDON
Item structure
Label: 9px mono --text-muted. Value: 9px mono --text-secondary. Gap: 6px. Separator between items: 20px gap (no visual divider).
Accuracy color
If > 65% = --green. If 50–65% = --amber. If < 50% = --red. This is a live data quality signal.
Session value
LONDON / NEW YORK / TOKYO / SYDNEY based on UTC time. Color --text-secondary normally, --gold during most active overlap hours.
06 —ANIMATION & MOTION RULES
▼

Terminals don't dance. Every animation has a job. If it doesn't communicate state change or live data, it doesn't exist.

ALLOWED ANIMATIONS
Ticker scroll
@keyframes translateX(-50%). 30s linear infinite. Pauses on hover. This communicates "live market data flowing."
Status dot pulse
@keyframes opacity 1→0.4→1. 2s ease-in-out infinite. Only on the MT5 live status dot. Communicates "heartbeat of live connection."
Bar fill transitions
transition: width 0.8s ease. Only on MTF bars and confidence bars when data updates. Not on page load.
Color transitions
transition: color 150ms. transition: background 150ms. On all hover states. Fast — terminals respond instantly.
Price flash
When a price updates, flash background rgba(color, 0.15) for 400ms then fade out. Green flash for up tick, red for down tick.

07 —NEXT.JS IMPLEMENTATION NOTES
▼
COMPONENT ARCHITECTURE
app/ layout.tsx — Terminal shell (topbar + 3-col grid) components/ Topbar.tsx — Brand + ticker + status + clock LeftNav.tsx — Nav + asset blocks + model status MainContent.tsx — Tab row + content grid + bottombar RightPanel.tsx — MTF + CSM + news + risk cards/ MetricCard.tsx — Reusable metric with accent bar SignalTable.tsx — Opportunity runway table SMCPanel.tsx — SMC structure rows ChartSVG.tsx — Inline SVG chart renderer NewsItem.tsx — News with decay score
DATA FLOW
Polling interval
useEffect with setInterval 3000ms. Fetches /api/predict_all. Updates React state. Components re-render only changed values.
Price ticks
Separate 2000ms interval for /api/ticks — lighter endpoint, just prices. Updates ticker + asset blocks.
News feed
60000ms interval. News doesn't change every 3 seconds. Also recalculates decay scores client-side every 60s.
Decay calculation
Client-side: decayScore = Math.exp(-λ * minutesSince). λ = ln(2) / 90. Run on every news render, not from backend.
CSS variables
Define all 20 color variables in :root in globals.css. Reference everywhere. Never hardcode hex in component files.
PERFORMANCE RULES
No chart library
Inline SVG only. No recharts, no D3, no Chart.js. This keeps the bundle lean and gives pixel-perfect control.
No layout thrash
Update .textContent directly for price ticks. Don't re-render parent components. Use refs for live price elements.
overflow: hidden
On ALL containers. The terminal never scrolls as a page. Only right panel scrolls internally (overflow-y: auto).
08 —THE APEX IDENTITY DETAILS
▼

These are the five details that make APEX unmistakably different from every other trading UI on the planet. Guard them.

THE 5 FINGERPRINTS
1. Decay scores
Every news item shows "decay: 0.82" in gold mono. This is your exponential decay output made visible. No Bloomberg, no TradingView, no competitor shows this. It is APEX's intellectual signature.
2. Kelly in the statusbar
The bottom strip shows live Kelly fraction (0.23) and calculated lot size (0.08) updated every signal run. Traders see position sizing as a live output, not a static setting.
3. Consensus score, not just signal
The ensemble confidence (84.7%) + "3/4 TF ALIGNED" shown simultaneously. Not just BUY — but how certain, and across how many timeframes. This is the ConsensusEngine made visible.
4. SMC zones on chart
OB and FVG zone rectangles drawn directly on the price chart as rgba fills with labeled borders. Most charting platforms require manual drawing. APEX draws them from the ML pipeline automatically.
5. CSM as capital flow
The 6-currency grid with +/- values framing the signal context. A BUY on USDJPY with USD at +2.4 and JPY at -3.1 is a very different trade than the same signal with balanced CSM. The grid makes that visible at a glance.
